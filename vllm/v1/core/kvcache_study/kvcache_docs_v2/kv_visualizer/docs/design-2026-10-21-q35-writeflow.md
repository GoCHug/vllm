## 2. 步序数据模型(固化常量 = meta layer_names + 本会话已验证几何)

- 池 j(0..5) = 4 个连续层：mamba **L4j/L4j+1/L4j+2 = A/B/C 组(slot 2/3/4)** + attn **L4j+3(块表[1])**。
- 阶段1：L0→L23 每层一步。mamba 步 = 写 conv 段行 slot + K≡ssm 段 ssm 行 slot；
  attn 步 = 写 K(1)+V(1)——1024 落 K/ssm 段行 1；**2048 落行 2-3 跨双格，同时给已写
  ssm(2)/ssm(3) 打 ↯被踩标**（每池的 attn 步都红一次 = 6 次覆盖）。
- 阶段2(decode 浓缩，pool0)：d1 mA 重写 ssm(2) → **反咬 K(1) 前半**；d2 mB 重写 ssm(3) →
  反咬 K(1) 后半；d3 mC ssm(4) 完好；d4 attn 读 K(1) → 2048 前半混 fp32 位型 → NaN ✕ →
  输出 `1!!!!!!!!!`；1024 全程绿。
- 冲突日志条：卡底滚动区逐条记红/绿事件(覆盖/反咬/NaN/正常归位)。

## 7. v3 修订（2026-10-21 用户规格三，同日闭环）

用户三点：①去掉双行视角，每池单行演示；②1024 时 K(1) 块画成与 ssm 块**一样大**（不会覆盖）；
③2048 时 K(1) 块是 ssm 块的**两倍大**（导致覆盖）。

落地（状态机 flowState 零改动，仅渲染层重写）：
- 每池 3 条 `.q35ftrack` 单行轨道（5 等分底格 = 块 id 0-4，格 = ssm 块宽恒 1MiB），废除 v2 双行视角；
- **K(1)/V(1) 改为绝对定位浮块** `.q35fkabs`：left/width 随 block_size 倍增——
  1024 = left 20% / width 20%（1 格宽≡ssm 等宽，落行 1 空闲位，不覆盖任何块）；
  2048 = left 40% / width 40%（2 格宽 = 2×ssm，从行 2 起整段红斜纹覆盖 ssm(2)∪ssm(3)）；
- V 段同构：V(1) 浮块同倍宽（2048 也跨 2 格）但 V 段独占不撞（绿）——与 K 同落位不同命运的核心对比；
- 咬斑 ▛▟/✕NaN/读写标记（金框=写/蓝R=读）全部沿用于浮块；顺手修 kssmTrackHTML 底格 title
  `${span}` 字面量 bug（三元分支普通字符串未做模板插值）。
